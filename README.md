# 🎟️ 쿠폰함 — 기프티콘·쿠폰 보관함 (PWA)

사진첩에 묻혀 기한을 놓치던 기프티콘·쿠폰을 **사진으로 담아 두고, 기한이 가까운 순서로** 꺼내 쓰는 혼자 쓰는 쿠폰함.

- 주소: https://bswjys.github.io/coupon-box/
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 열려요.

## 되는 일

| 기능 | 설명 |
| --- | --- |
| 첫 화면 2열 그리드 | 첫 칸이 **＋ 쿠폰 사진등록** 카드, 옆과 아래에 쿠폰 카드(사진 썸네일 · 브랜드/쿠폰명 · D-day 배지) |
| D-day 자동 정렬 | 사용 가능 탭에서 기한 임박 → 먼 기한 → 기한 없음 → 기한 지남 순으로 자동 정렬 |
| 임박 배지 | D-3 이내 빨강, D-7 이내 주황, 그 밖은 회색. 지난 쿠폰은 ‘기한 지남’ |
| 사용완료 탭 | 쓴 쿠폰은 따로 모아 최근에 쓴 순서로. 되돌리기도 가능 |
| 상세 · 바코드 확대 | 사진을 누르면 **흰 배경 고대비 전체화면**으로 확대 (계산대에서 그대로 보여 주기) |
| 사진 자르기 | 찍거나 고른 사진을 바로 담지 않고 그 자리에서 잘라 담기. 모서리·박스 안쪽 드래그, 비율 자유·1:1·3:4·4:3, ↺ 90° 회전, 원본 그대로 |
| ✨ 자동 맞춤 | 크롭 창을 열면 어두운 배경 위 밝은 쿠폰 카드 영역을 찾아 자를 곳을 미리 맞춤. 못 찾으면 전체로 폴백, 버튼으로 다시 맞추기 |
| 금액권 잔액 | 금액권이면 금액과 남은 잔액을 적고, 상세에서 잔액만 바로 고치기 |
| 카테고리 · 준 사람 · 검색 | 카페·간식 / 외식·치킨 / 마트·편의점 / 기타, 준 사람·메모 기록, 브랜드·쿠폰명·준 사람 검색 |
| 백업 · 복원 | 쿠폰과 사진을 JSON 한 파일로 내려받고 되살리기 |
| 오프라인 | 한 번 열면 지하철에서도 열림 (Service Worker 캐시) |

## 저장 방식

- **IndexedDB** (`coupon-box` → `coupons`) 에 쿠폰과 사진을 함께 저장. 사진은 긴 변 1600px · JPEG(0.82)로 압축해 쿠폰당 최대 3장.
- 서버·계정·실시간 공유 없음. 이 기기의 저장 공간에만 남고, 외부로 나가는 요청은 0건.
- IndexedDB를 못 쓰는 환경(사생활 보호 모드 등)에서는 localStorage로 자동 대체.

## 파일

```
index.html            화면 구조 (2열 그리드 · 등록/상세/백업 시트)
styles.css            토스 스타일 스타일시트
app.js                IndexedDB 저장 · D-day 정렬 · 사진 압축 · 백업/복원
sw.js                 오프라인 캐시 (coupon-box-v3)
manifest.webmanifest  PWA 설정
icon.svg              앱 아이콘 (꽉 찬 파랑 사각형 + 흰 티켓)
icon-180/192/512.png  홈 화면·PWA 아이콘
make_icons.py         아이콘 생성기
test_app.py           자동 검증 (Playwright)
```

## 검증

```bash
LD_LIBRARY_PATH=/workspace/.browserlibs/lib python3 test_app.py
```

사진 등록·압축, D-day 정렬과 배지 색, 사용완료 이동/되돌리기, 바코드 확대(흰 배경), 잔액 수정,
검색·카테고리, 백업/복원, 390·1280 가로 넘침 0, 입력 칸 font-size 16px 이상, 콘솔 오류 0, 오프라인을 확인한다.
